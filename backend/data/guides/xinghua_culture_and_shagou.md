# 兴化名人文化与沙沟水上古镇

## 板桥故里与水浒文化
- **郑板桥故居与纪念馆**：
    - 地址：兴化市东城外街道
    - 特色：“扬州八怪”核心代表郑板桥出生与生活之地，粉墙黛瓦，竹影婆娑，展出板桥墨竹真迹与书画拓片。
    - 建议游玩时长：1.5 小时。
- **施耐庵陵园**：
    - 地址：兴化市新垛镇施家桥
    - 特色：《水浒传》作者施耐庵的长眠之地与文风纪念馆，适合水浒文化与古典文学爱好者打卡。

## 沙沟古镇（水乡慢城风情）
- **沙沟古镇**：
    - 地址：兴化市沙沟镇（大泽湿地腹地）
    - 核心亮点：三面环水，保存着古石桥、古当铺、大士禅林等明清遗迹。相比商业化景区，这里保留着最纯粹的水乡渔家生活方式。
    - 必尝特色：沙沟大鱼头、沙沟鱼圆、藕夹。
    - 建议游玩时长：2.5 小时。
