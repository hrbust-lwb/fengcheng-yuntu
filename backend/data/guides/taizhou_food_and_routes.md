# 泰州全域美食与路线规划要点

## 特色美食与伴手礼指南
- **靖江蟹黄汤包**：相比市区早茶汤包，靖江汤包个头更大、蟹黄更足、皮薄如纸，靖江国际大酒店或南园宾馆为传统名店。
- **黄桥烧饼**：源自泰兴黄桥镇，外酥里嫩，有咸甜、肉松、葱油等多种口味。
- **中和桥老肉圆 / 宣堡小馄饨**：泰州街头巷尾的经典地道市井小吃。

## 空间路线与避坑规则（严禁折返跑）
- **海陵主城区 1 日线**：古月楼早茶 -> 乔园 -> 望海楼/梅苑 -> 泰州老街漫步 -> 凤城河夜游。所有 POI 集中在海陵区 3-5 公里范围内，适合打车或步行。
- **姜堰生态 1 日线**：海陵出发 -> 驱车 35 分钟至溱湖湿地公园 -> 溱潼古镇午餐尝溱湖八鲜 -> 傍晚返回主城。
- **兴化风光 1 日线**：海陵出发 -> 驱车 1 小时至李中水上森林 -> 千垛景区 -> 兴化市区品尝大闸蟹 -> 返回。
