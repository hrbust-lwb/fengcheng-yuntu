# 海陵老城深度与高港沿江人文

## 海陵稻河古街区与市井烟火
- **稻河古街区**：
    - 地址：海陵区稻河路
    - 特色：泰州最完整、最具市井气息的古街区，涵西街与五一路交汇处保留了大量清代江淮合院民居、科学馆与古水井，游客较老街少，更清幽。
    - 建议游玩时长：1.5 小时。
- **柳园与评话文化**：
    - 地址：海陵区迎春西路凤城河畔
    - 特色：纪念中国说书评话宗师柳敬亭，园内依水建廊，常有评话、打鼓演出与民间茶社。
- **坡子街与老城夜市**：
    - 特色：海陵核心市井商业街区，汇集宣堡小馄饨、泰州老肉圆、臭豆腐与麻油油饼等夜市小吃。

## 高港口岸雕花楼与海军文化
- **口岸雕花楼景区（4A级）**：
    - 地址：高港区口岸街道
    - 核心亮点：“江左第一楼”，清代私家建筑的木雕巅峰之作，整栋楼雕梁画栋、图案无一重复，展现江淮富商的建筑美学。
    - 建议游玩时长：2 小时。
- **中国人民解放军海军诞生地纪念馆（白马庙）**：
    - 地址：高港区白马镇
    - 核心亮点：1949年中国人民解放军海军初创圣地，馆内陈列大量水面舰艇模型、退役战机与珍贵历史实物，是国防与军事爱好者的必访之地。
    - 建议游玩时长：1.5 小时。
