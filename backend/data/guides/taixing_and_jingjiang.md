# 泰兴与靖江深度文旅与美食指南

## 泰兴古银杏森林与黄桥古镇
- **泰兴国家古银杏森林公园**：
    - 地址：泰兴市宣堡镇
    - 核心特色：拥有全国最大规模的古银杏群落，深秋（10月下旬-11月中旬）满目金黄，适合摄影采风、亲子休闲。
    - 建议游玩时长：2.5 小时。
- **黄桥古镇与黄桥战役纪念馆**：
    - 地址：泰兴市黄桥镇
    - 核心亮点：千年历史名镇，拥有大片明清院落与红色战役遗址；同时黄桥也是“东方提琴之都”，全球半数以上小提琴产自这里。
    - 必尝美食：正宗黄桥烧饼（外层芝麻密布，酥脆咸香，推荐肉松与葱油馅）。
    - 建议游玩时长：2 小时。

## 靖江江鲜与非遗汤包朝圣
- **靖江蟹黄汤包**：
    - 代表名店：靖江南园宾馆、鸿运酒楼。
    - 特色：相比海陵早茶汤包，靖江汤包制作技艺入选非物质文化遗产，皮薄透明几近吹弹可破，蟹黄蟹肉比例极高，汤汁浓郁醇香。
- **牧城公园与滨江湿地**：
    - 地址：靖江市滨江新城
    - 特色：长江北岸的大型生态湿地公园，可远眺江面轮船往来与江阴大桥雄姿，适合日落骑行。
    - 特产手信：靖江双鱼牌猪肉脯（传统竹筛炭烘工艺，甜咸鲜香）。
